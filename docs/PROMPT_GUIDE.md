# MiniMax H3 prompt guide / 提示词指南

A practical H3 prompt usually contains five parts:

1. Subject and scene.
2. Chronological action sequence.
3. Physical reaction of materials or the environment.
4. One dominant camera path.
5. Lighting, style, constraints, and the final frame.

实用的 H3 Prompt 通常包含五部分：

1. 主体与场景。
2. 按时间展开的动作顺序。
3. 材质或环境产生的物理反馈。
4. 一个占主导地位的运镜路径。
5. 光线、风格、约束和最终画面。

Template:

```text
[Shot size] of [subject] in [environment].
[First action], then [second action], while [environment response].
The camera [one clear camera movement].
[Lighting and visual style].
End with [final state]. [Positive constraints].
```

Official documentation notes that camera instructions such as `[pan]`, `[zoom]`,
and `[static]` may be placed after key descriptions. Keep the action achievable
within the selected 4–15 second duration.
